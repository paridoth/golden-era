GOLDEN ERA — FACTORY PLAYTEST 0.1.11

An early voxel survival and automation playtest built from existing Luanti mods.
This is an independent community game pack, not Minecraft or the FTB Revelation
modpack. The first workshop is ready to operate and expand.

START

Extract the whole ZIP before launching. Do not run files inside the ZIP viewer.

Windows 10/11 (64 bit): double-click start.bat. The first launch downloads the
official Luanti 5.17.0 portable engine (~18 MB) from GitHub and verifies SHA-256
before launching. Internet is needed for that first engine download. Later
launches use the cached engine. No admin installation or Java is needed.
The black window that opens with the game shows loading progress, such as each
mod as it loads, so you can tell it is still working. Leave it open while you
play; it closes with the game.
The Windows launcher still needs its first native Windows tester run.

Linux: install Luanti 5.17.0, then run ./start.sh from this folder. The launcher
finds the native luanti command or the official Flatpak. If your extractor drops
executable permissions, run: chmod +x start.sh

macOS: install Luanti 5.17.0, then open start.command. This launcher is provided
for testing and has not been verified on a Mac.

Official engine downloads: https://www.luanti.org/en/downloads/

PLAY

The launcher opens the main menu with Golden Era selected. Pick the ready-made
"playtest" world, or press New to make another world, then press Play Game.
Choose the supplied workshop to try machinery with tools and spare materials,
or choose survival to gather your own materials without granted supplies.
Damage is off by default. Existing players keep their position and inventory.
Allow time for initial world generation. Preparing the workshop shows a loading
message while you keep exploring. Arrival is automatic; /cancelworkshop cancels
the trip. Disconnecting saves an unfinished trip for your next login.

W/A/S/D move, mouse looks, Space jumps. E opens and closes the inventory, and E
or Esc closes any other game screen. Hold Left Ctrl while walking to sprint.
Right-click machines to open them. Left-click digs or takes items from drawers.
K toggles flight and J toggles fast movement; Left Ctrl flies faster.
Keys can be changed in Settings > Controls.

PLAY TOGETHER ON YOUR HOME NETWORK (LAN)

Every player installs the same Golden Era version on their own computer.
Host: in the main menu select a world, tick "Host Server", enter your player
name and a password, then press Host Game. Windows may ask to allow Luanti
through the firewall: allow it on private networks. Find your local address
with "ipconfig" in a Command Prompt (IPv4 Address, for example 192.168.1.20).
Others: open the Join Game tab, enter the host's address and port 30000
(or the port shown on the host), choose a different name and password, and
press Join. Everyone on the server can fly and move fast. The host keeps
admin rights. The host continues as their single-player character: items,
armor, experience and position carry over, and progress made while hosting
returns to single player. For a world last played before 0.1.10, open it alone
once first, then host it.

/packhelp   Workshop instructions
/packversion   Version and build details for a bug report
/factoryguide   Early survival and machinery guide
/goals   Ten starter goals with small rewards; hide the on-screen goal here
/lookinfo   Turn the block name, mod and power line at the top of the screen off or on
/startchoice    Reopen the starting choice before choosing a path
/workshop   Return to the workshop
/explore    Return to your original survival spawn
/gamemode creative   Full item catalog for building experiments
/gamemode survival   Ordinary item quantities again

The optional supplied coal generator powers a cell, Pulverizer and furnace. Two raw iron
become four ingots, delivered through tubes into the output barrel. The first
batch takes about two minutes. The front-left barrel holds spare materials and
parts. Use the Elepower Tome and inventory recipe guide to learn more.
Filter-injectors resist piston movement in this build. Mine and place them to
relocate them, then configure their selectors again.

The factory guide explains the hand-cranked grindstone, coal-fired alloys,
electronics, first power, item routing and a small renewable wheat farm. Seven crafting milestones use the
existing advancement system (/awards). The extra workshop alloy furnaces can
be wired with the supplied conduits. Explore, build and report confusing parts.
New workshops include a planter, harvester, seeds, soil, bone meal, one wheat
for filter setup and two blinking controls in the supplies barrel. Follow the
Farming guide page to build a small seed-return line.
The Trees page explains one oak-harvesting cycle using the same machines and
an Adjustable Vacuum Tube. Keep spare saplings: their drops are random.
Existing worlds keep their barrels unchanged; use recipes or the workshop's
creative catalog to try the new machinery without replacing your save.

SAVES AND FEEDBACK

Windows saves/logs: %LOCALAPPDATA%\GoldenEraPlaytest
Linux saves/logs:   ~/.local/share/golden-era-playtest
macOS saves/logs:   ~/Library/Application Support/GoldenEraPlaytest

Close the game normally to save. Keep that data folder when replacing the game
ZIP with a later build. The game package contains no existing player world.
If an existing save has the wrong game ID or lacks its world.mt, the launcher
leaves it untouched and asks you to choose another data folder or restore it.

For a bug report, copy /packversion, then send what you did, what you expected, what
happened, and a screenshot if useful. The client log is logs/client.log inside
the save-data folder. Review logs before sharing them.

This is an early single-player playtest, not a complete Revelation recreation.
