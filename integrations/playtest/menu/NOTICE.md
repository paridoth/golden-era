# Original main menu header

`header.png` (960x120) replaces Mineclonia's menu header in the assembled game.
`make_header.py` draws it from the pixel font defined in that script; no
external font or image pixels are used. Rerunning the script reproduces it.

To the extent permitted by law, the project contributors dedicate this original
image under CC0 1.0 Universal (SPDX: CC0-1.0), including the waiver and fallback
license. See `../../../LICENSES/CC0-1.0.txt` and
https://creativecommons.org/publicdomain/zero/1.0/ . The other menu images
(icon and background overlays) remain Mineclonia's.
