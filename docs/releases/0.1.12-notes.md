## ⬇️ Windows testers: [download the installer (golden-era-playtest-0.1.12-windows.exe)](https://github.com/paridoth/golden-era/releases/download/v0.1.12/golden-era-playtest-0.1.12-windows.exe)

Open the downloaded EXE. It installs, adds desktop and Start Menu shortcuts, and opens the game menu. The first launch downloads the official Luanti 5.17.0 engine (about 18 MB), so it needs internet. The EXE is unsigned: if SmartScreen warns, choose **More info → Run anyway**.

**New in 0.1.12**

- **Hammer:** mines a 3x3 square of stone across the direction you're looking.
- **Excavator:** digs a 3x3 square of dirt, sand and other shovel blocks.
- **Lumber axe:** fells a whole tree from one chopped log.
- **How to make them:** add four seared bricks to a pickaxe, shovel or axe head cast for a Hammer Head Cast (864 mB), Excavator Head Cast or Broad Axe Head Cast (576 mB each), then cast the head and assemble the tool like the others.
- Large tools dig at half speed but last three times longer. Sneak to dig a single block. They only dig blocks the tool could harvest, so an iron hammer leaves obsidian.

The Tools page of the factory guide covers the new casts.

**Other downloads**

- Windows ZIP fallback (no installer): golden-era-playtest-0.1.12-windows-test.zip. Extract it all and run start.bat.
- Linux: golden-era-playtest-0.1.12-linux.tar.gz. Extract it and run the included launcher with Luanti 5.17 or the official Luanti Flatpak; see START-HERE.txt.

Existing saves and settings carry over. LAN hosting between two machines hasn't been tested yet. Report problems with the output of `/packversion`.
